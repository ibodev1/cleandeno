# 🏁 Clean Deno

`deno info` package to clean the inside of directories ending with cache from
incoming deno directories.

[![GitHub](https://img.shields.io/github/license/ibodev1/cleandeno)](https://github.com/ibodev1/cleandeno/blob/main/LICENSE)
[![Made by ibodev1](https://img.shields.io/badge/made%20by-ibodev1-0082fb)](https://github.com/ibodev1)
[![TypeScript](https://img.shields.io/badge/types-TypeScript-blue)](https://github.com/ibodev1/cleandeno)

## ⭐ Getting started

```bash
deno run -A jsr:@ibodev/cleandeno
```

You can also install it globally using the following:

```bash
deno install --global -A -n cleandeno jsr:@ibodev/cleandeno
```

Then, the package is available to run:

```bash
cleandeno
```

### Configuration

Required permissions:

1. `--allow-run`
2. `--allow-read`
3. `--allow-write`
